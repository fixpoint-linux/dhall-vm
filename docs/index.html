What it does

Typecheck

Bidirectional inference with helpful Error: … at line N, col M messages.

Normalize

Eager, step-sound normal forms for a single-term de Brüijn core.

Serializers

One value tree → JSON, TOML, and YAML output.

Imports

./x and env:NAME (file imports disabled in the browser).

Optional / Some

Some, None, and pattern-free optional handling.

Arithmetic

Natural arithmetic on arbitrary-precision big ints.

assert

assert : type-level checks that fail fast.

toMap

Turn record field sets into List map entries.

Quickstart

Build the native binary (a Cosmopolitan APE) and run the whole test suite:

make            # dhall.com (APE) + dhall.com.dbg (ELF)
make test       # run.sh + roundtrip.sh + examples.sh + cli.sh

Usage:

dhall typecheck [file|-]   # infer the type of an expression
dhall normalize [file|-]   # print the normal form
dhall to-json   [file|-]   # evaluate to JSON
dhall to-toml   [file|-]   # evaluate to TOML (top level must be a record)
dhall to-yaml   [file|-]   # evaluate to YAML (block style, 1.2 core schema)

Rebuild the in-browser WASM (requires emscripten clang lld llvm):

make wasm            # scripts/build-wasm.sh → docs/dhall.js + docs/dhall.wasm
node tests/wasm-smoke.js   # headless browser-API smoke test (6 checks)
